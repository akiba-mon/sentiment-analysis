# Key Results (MSc Dissertation)

- Task: Sentiment classification on social media text (Twitter).
- Dataset: Sentiment140 (~1.6 million tweets).
- Features: TF-IDF with n-grams.
- Models compared: Logistic Regression, Linear SVM, Naïve Bayes, SGD.
- Selected model: Logistic Regression (interpretable baseline with strong performance).
- Best test accuracy: 82.6%.

## Interpretation
Feature-weight analysis was used to inspect influential tokens for positive and negative sentiment and support interpretability.
