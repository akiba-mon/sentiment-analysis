# Dataset Instructions

## Dataset Used

This project uses the Sentiment140 dataset for sentiment classification of social media text.

Dataset source:

https://www.kaggle.com/datasets/kazanova/sentiment140

## Dataset Description

- Approximately 1.6 million tweets
- Binary sentiment classification
- Negative sentiment = 0
- Positive sentiment = 4 (converted to 1 during preprocessing)

## Why the Dataset Is Not Included

The dataset is not included in this repository because of file size considerations and dataset distribution restrictions.

## Reproducing the Project

1. Download the Sentiment140 dataset from Kaggle.
2. Extract the CSV file.
3. Rename the file to:

senti.csv

4. Place the file in the project root directory.
5. Run the notebook in the notebooks folder.
